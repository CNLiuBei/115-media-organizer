115 媒体整理

设置

筛选、目录结构和元数据。扫描与整理仍在侧边栏完成。

使用流程

  1. 在 115 打开文件夹进入要整理的目录
  2. 侧边栏点「同步」读取当前目录 CID
  3. 扫描并校对改片名、路径并勾选
  4. 底部执行整理确认后重命名 / 移动

TMDB 片名校准

可选：在 TMDB API 设置 申请。不填也可以，扩展会走网页搜索（国内通常可用）。

扫描与筛选

只用于扫描预览筛选，不作为清理时「是否还有正片」的门槛。填 0 表示不按体积过滤。

主要用于扫描与 TMDB；整理已改为批量移动，批次间隔固定很短，接近官网多选移动。

整理默认行为

选「指定网盘目录」后，具体目录在侧边栏点「选择…」指定并在浏览器中保留。

清理会先删推广图/广告包等垃圾，再把已无有效视频的子文件夹移入回收站（不删扫描根；cid=0 时跳过自动清理）。
