# 115 媒体整理

Chrome / Edge Manifest V3 浏览器扩展：在已登录的 [115 网盘](https://115.com) 中扫描媒体文件，解析剧集/电影命名，可选对接 TMDB / 豆瓣补全信息，预览后批量重命名并按规则建文件夹移动。

## 功能

- 按扩展名与最小体积筛选视频 / 音频 / 字幕 / 图片
- 解析 `S01E02`、`S01EP02`、`1x02`、`第1季第2集`、`第02集`、`上/下集`、`SP01`、`片名 (2023)` / `2023年`、多碟 `Part.2` 等
- 可配置路径与文件名模板；预设「视频库（地区分类）」/ 标准 / Jellyfin 等
- 整理：**批量**建目录 / 重命名 / 移动（同目标一次 `files/move`，接近官网多选）
- **TMDB 片名校准**：同一剧集只查一次；API 不可用时自动走网页搜索
- 整理后可**自动清理无视频文件夹**（进回收站）
- 字幕 / NFO 可跟随同名视频一起整理
- 侧边栏预览表：勾选、改名、改路径后再执行；支持视图筛选（全部 / 待整理 / 已在位 / 低置信 / 冲突）、重复集与缺集提示、目标路径冲突检测
- 整理失败或中途停止后可一键「重试失败」；「复制整理清单」可将目标文件路径导出到剪贴板
- 115 页面注入「媒体整理」入口，自动同步当前目录 CID

## 安装

1. 打开 Chrome / Edge，进入 `chrome://extensions`（或 `edge://extensions`）
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目目录（含 `manifest.json` 的文件夹）
4. 固定扩展图标；点击图标即可打开侧边栏

## 使用

1. 浏览器打开并登录 [https://115.com](https://115.com)
2. 进入要整理的目录
3. 点击页面上的「媒体整理」按钮，或点击扩展图标打开侧边栏
4. （可选）在设置页填入 TMDB API Key，侧边栏勾选「TMDB 片名校准」
5. 确认 CID 后点击「扫描」
6. 在「整理后的文件夹」选择目录结构；若要输出到别处，选「指定网盘目录」→「选择…」浏览文件夹
7. 在预览表中核对校准后的片名、新文件名与目标路径
8. 点击「执行整理」

建议先在小目录试跑。改名/移动为真实操作；清理无视频夹会进 115 回收站，可还原。

## 设置

扩展选项页可配置：

| 项 | 说明 |
| --- | --- |
| TMDB API Key | 在 [TMDB](https://www.themoviedb.org/settings/api) 申请（v3 Key 或 v4 Token），用于片名校准 |
| 默认开启校准 | 扫描时自动用 TMDB 校正片名 |
| 豆瓣补充 | 可选；TMDB 无中文名时用豆瓣补中文 |
| 最小体积 | 默认 50MB，降低样本片误伤 |
| 扫描/校准间隔 | 默认约 200ms；整理为批量请求，批次间隔很短 |
| 清理无视频夹 | 移动整理后删除扫描目录下已无视频的残留文件夹 |
| 目录结构 | **Emby 标准** / Emby (English) / 视频库（按地区） / 视频库（大陆→电视剧） / 无类型根目录 / 仅按片名 / 自定义；剧集支持 `{region}` |
| 整理到 | 扫描目录下，或指定网盘目录（侧边栏浏览选择） |
| 根路径前缀 | 可选，加在布局路径前，如 `媒体库` |
| 路径/文件名模板 | `{title}` `{year}` `{season}` `{episode}` `{season:02d}` `{episode:02d}` `{ext}` `{region}` `{part}` `{date}` `{edition}` `{tmdbid}` `{tmdb}`（渲染为 `{tmdb-71712}`，无 ID 时为空）`{folder}`（渲染为 `良医 (2017) {tmdb-71712}`，年份/ID 缺省时省略） |
| 版本信息地址 | 可选；指向仓库 `update.json` 的 Raw 地址，侧边栏每天打开时对比一次版本，有新版显示提示条（可点 ✕ 忽略该版本）。以开发者模式加载的扩展无法真正自动更新，需手动 `git pull` / 下载后重启浏览器 |

默认「Emby 标准」：

- 剧集：`剧集/剧名 (年) {tmdb-id}/Season {season:02d}`（例：`良医 (2017) {tmdb-71712}`）
- 电影：`电影/片名 (年) {tmdb-id}`
- 再次扫描时会从目录名识别年份与 TMDB ID，避免重查错剧
- `{region}`：`大陆剧` / `港台剧` / `日韩剧` / `欧美剧` / `动漫` / `其他剧集`（由文件名、已有路径、可选 TMDB 产地推断）

「视频库（按地区）」会把剧集放在 `剧集/{region}/剧名 (年) {tmdb-id}/Season {season:02d}`；
「视频库（大陆→电视剧）」则把大陆剧放进 `电视剧/`，其余仍进 `剧集/{region}/`。

## 权限说明

- `sidePanel`：打开侧边栏；`storage`：保存设置与 CID；`tabs`：定位当前 115 标签页并读取目录 CID
- `host_permissions` 仅包含 115 网页与接口（`webapi.115.com`）、TMDB、豆瓣电影搜索，以及 `raw.githubusercontent.com`（可选的版本检查）
- 使用你登录 115 后的 Cookie（由浏览器随请求自动携带；扩展不读取、不存储 Cookie 内容）
- **不上传、不存储账号密码**


## 注意

- 需已登录 115 网页版；未登录时扫描会失败
- 批量操作过快可能触发安全验证：调大请求间隔，在网盘页完成验证后重试
- 豆瓣接口非官方，可能不稳定；可仅用本地解析或 TMDB
- 清理仅删除「整棵子树无视频」的文件夹，且不会删扫描根目录；`cid=0` 时跳过

## 开发

纯原生 JS，无构建步骤。修改代码后在扩展管理页点击「重新加载」即可。

```bash
node tools/parser-selftest.js      # 文件名解析回归
node tools/folder-meta-selftest.js # 目录年/TMDB/已在位检测
```
